# SafeCheck - Sistema de Inspeção e Checklists

Um sistema moderno de inspeção tipo checklist que permite adicionar usuários responsáveis para realizar correções.

## Features

- ✅ Autenticação com email/senha e SSO (Google, Microsoft)
- ✅ Dashboard com estatísticas e resumo geral
- ✅ Fluxo de 4 etapas: Seleção → Checklist → Execução → Resumo
- ✅ Capture de fotos para não conformidades
- ✅ Geração e compartilhamento de relatórios (PDF, WhatsApp, E-mail)
- ✅ Filtros e busca de relatórios
- ✅ Gestão de empresas e unidades
- ✅ Templates de checklists padrão e personalizados

## Stack

- **Frontend**: React + TypeScript + Vite + Tailwind CSS
- **Backend**: Node.js + Express + TypeScript
- **Database**: PostgreSQL
- **Auth**: JWT + OAuth2
- **Storage**: Suporte a imagens
